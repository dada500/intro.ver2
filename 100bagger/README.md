# 다다의 100배주식 — 자동화 파이프라인 설계

기존 수작업 4단계(종목 선정 → 엑셀 지표 분석 → AI 스크립트 → 영상 제작)를
그대로 살리되, 사람이 판단해야 하는 두 지점(종목 확정, 업로드 전 검수)만 남기고 나머지를 자동화하는 구조.

```
[주 1회 cron]
  │
  ▼
① RS 스크리닝 ──► ② 재무 수집·엑셀 자동 입력 ──► ③ 점수화 + 👤 다다 승인
                                                         │
                                                         ▼
⑥ 유튜브 업로드(비공개/예약) ◄── 👤 검수 ◄── ⑤ 영상 생성 ◄── ④ AI 리서치 → 스크립트(.docx)
```

> **v2 변경 (2026.11 검증 결과 반영):** RS 80 이상과 이동평균 위는 선정 필터에서 뺌.
> 다다 종목 114개로 검증해보니, RS가 높았던 종목은 1년 땐 더 올랐다가 현재까지는 −29% vs +3%로 오히려 더 많이 빠짐 (p=0.02).
> 이동평균 위인지는 통과·탈락 차이가 없었음.
> 그래서 이제 **1차 = 조정영업이익 흑자 + 개선** (재무 필터)이고, RS는 "과열 경고등"(RS 높고 적자 = 소액만/익절)으로만 씀.
> 아래 ①은 후보를 넓게 모으는 용도로만 쓰고 걸러내는 기준으로는 쓰지 않음.
> 자세한 내용은 `pjr_analysis/1차필터_검증결과.md`, 요약은 `종목선정기준_A4.pdf`.

## ① RS(상대강도) 후보 수집 — `stage1_rs/` (v2: 걸러내지 않고 수집·경고용)
- **유니버스**: 미국 NYSE/NASDAQ 전 종목 + KOSPI/KOSDAQ.
- **RS 점수 (IBD 방식)**: `0.4×3개월 + 0.2×6개월 + 0.2×9개월 + 0.2×12개월` 수익률을 계산한 뒤, 유니버스 전체에서 백분위(1~99)로 순위를 매김.
- **필터** (엑셀 D1 메모 기준):
  - 시총 10억~500억 달러 (한국은 1조~50조 원)
  - RS ≥ 80
  - 주가가 50일·200일 이동평균 위
  - 일평균 거래대금 하한
  - 매출 성장률 > 20%
- **출력**: 후보 20~30개를 `candidates_YYYYMMDD.csv`로 저장. 이미 엑셀에 있는 종목은 "재분석" 표시.
- 데이터: yfinance(무료). 안정성이 필요해지면 유료 API로 교체.

## ② 재무 수집 → 엑셀 틀 자동 입력 — `stage2_financials/`
- 지금은 AI에게 "10개년 표 만들어줘"를 붙여넣는 방식인데, **숫자는 AI가 틀리기 쉬워서**(예: ORCL 시총이 476.4억불로 입력돼 있지만 실제로는 약 5,700억불) 원천 데이터로 바꾸는 게 좋음.
  - 미국: SEC EDGAR XBRL `companyfacts` API (무료, 10년 이상 데이터)
  - 한국: DART OpenAPI (무료, API 키 필요)
- 질문 형식 C2의 12개 항목을 계산:
  - 매출, 성장률, 매출이익, 영업이익, 영업이익률, 장기부채, 순이익, 주주자본, ROE, R&D
  - **조정영업이익 = 영업이익 + R&D**, 조정영업이익률
  - PER, **PJR = 시총 ÷ 조정영업이익**, 부채비율, 유동비율
- openpyxl로 `재무지표분석(연간)` / `(분기)` 시트의 기존 블록 형식(종목당 13행)에 그대로 추가.

## ③ 점수화 + 사람 승인
- 규칙 기반 점수: 매출 성장, **조정영업이익 개선 추세**, 흑자 여부, 부채비율 등.
  - PJR 수준 자체는 가중치를 낮게 둠 (근거는 `pjr_analysis/PJR_분석결과.md`).
- 다다가 엑셀 `결론` / `비고` 칸을 채우거나, 텔레그램·이메일 알림에서 ✅를 누르면 승인된 종목만 ④로 진행.

## ④ AI 리서치 → 스크립트 워드 — `stage4_script/`
- `질문 형식` 시트 C4~C12의 프롬프트를 **같은 대화 안에서 순서대로** 실행 (C11이 "위에서 나눈 내용들을 바탕으로"를 전제하기 때문).
  - Claude API + 웹 검색 도구 사용.
  - 순서: 사업모델 → 매출 → CEO → 해자(Mauboussin) → 당면 이슈 → 악재(전환사채 등) → 기술적 분석 → 스크립트
- ②에서 계산한 실제 숫자를 컨텍스트로 함께 넣어서 AI가 숫자를 만들어내지 않게 함.
- python-docx로 기존 워드 형식(`[N. 회사명]` 제목 + 인트로/1~4장/결론)대로 저장하고, 원 대화 로그도 부록으로 첨부.
- 투자 권유 면책 문구를 자동으로 삽입.

## ⑤ 영상 생성 — `stage5_video/`
- 이전에 쓴 프로그램이 **Vrew(브루)**였다면 (스크립트를 붙여넣으면 AI 목소리, 자막, 이미지가 붙는 한국 툴):
  - Vrew는 공개 API가 없음.
  - 1단계: 스크립트를 Vrew "텍스트로 비디오 만들기" 형식(문단 = 장면)으로 내보내고, 붙여넣기만 수동으로 함 (5분 정도).
  - 2단계(완전 자동): TTS(ElevenLabs / Typecast / CLOVA)로 음성 생성 → 주가 차트와 재무표 이미지는 matplotlib로 자동 생성 → 자막(SRT) → ffmpeg/MoviePy로 합성.
  - 차트와 재무표가 실제 데이터라서 오히려 기존 영상보다 정보량이 많아짐.

## ⑥ 업로드
- YouTube Data API v3로 **비공개 또는 예약** 업로드.
  - 제목 템플릿: `회사명(티커) 100배 주식 후보 분석 및 정보 공유`
  - 설명, 태그, 썸네일도 함께 업로드.
- 다다가 검수한 뒤 공개로 전환.

## 실행 환경
- 로컬 PC 또는 GitHub Actions 주간 cron.
- 필요한 키: Claude API, DART, (TTS), YouTube OAuth.
  - 모두 환경변수나 시크릿으로 관리하고 저장소에 커밋하지 않음.

## 진행 순서 제안
1. ① RS 스크리너
2. ② 재무 자동 입력
3. ④ 스크립트 자동 생성
4. ⑤ 영상(반자동 → 완전 자동)
5. ⑥ 업로드

①②만 있어도 주간 후보 리스트와 엑셀이 자동으로 채워짐.
